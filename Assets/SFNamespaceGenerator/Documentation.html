Welcome

The SF Namespace Generator is a Unity Editor tool designed to automate the creation and management of C# namespaces. If you've ever started a project and forgotten to add namespaces, or if you want to enforce a consistent structure across your team, this tool is for you.

It intelligently generates namespaces based on your folder structure, saving you time and preventing potential conflicts in larger projects.

Quick Start

Get up and running in less than a minute:

  1. Open the Tool: Navigate to Tools > Generate Namespaces in the Unity menu.
  2. Set Root Namespace: In the Configuration section, enter your project's base namespace (e.g., MyCompany.MyAwesomeGame).
  3. Select & Scan: In the Folders tab, ensure your target folder is set (it defaults to Assets), then click Scan Selected Folder.
  4. Generate: Switch to the Scripts tab, review the generated namespaces, and click Generate Namespaces... to apply the changes.

That's it! Your scripts now have consistent, well-organized namespaces.

Detailed Walkthrough

Opening the Window

Find the tool in the top Unity menu bar: Tools > Generate Namespaces.

Configuration

At the top of the window, you'll find the main settings:

  • Root Namespace: This is the base for all generated namespaces (e.g., YourCompany.YourGame).
  • Include Folder Structure: When enabled, the tool will build namespaces from your folder paths (e.g., YourCompany.YourGame.Player.Controllers). If disabled, all scripts will simply use the root namespace.

The Folders Tab

This tab is for setting up your scan and customizing folder-level rules.

  1. Target Folder: Specifies which folder the tool will scan for .cs files. Use the Browse button to select a folder within your Assets directory.
  2. Folder Namespace Overrides: This powerful feature allows you to override the generated namespace for any specific folder. The change cascades down to all subfolders unless they also have an override.
    • Simply type a new name in the text field next to a folder.
    • Click Reset to clear an override and revert to the default generated name.
  3. Scan Controls:
    • Scan Selected Folder: Starts the scanning process. The results will appear in the Scripts tab.
    • Expand All / Collapse All: Controls the view of the folder tree.

The Scripts Tab

After scanning, this tab shows you every script found and allows you to fine-tune the final output.

  1. Script List: Scripts are grouped by their parent folder.
    • Selection Toggle: Use the checkbox next to a script or a folder to include/exclude it from the batch generation.
    • Status: A label indicates if a script is an Editor script, Has Namespace, or has No Namespace.
    • Update: For scripts that already have a namespace, check the Update box to replace the existing one with the newly generated version.
    • Namespace Field: Shows the final namespace that will be applied.
    • Customize: Click this button to manually edit the namespace for a specific script. Click Reset to go back to the generated version.
  2. Selection Options: Use these buttons to quickly select or deselect scripts based on their status (e.g., "Select All", "Select Without Namespaces").
  3. Generate Button: Once you're happy with your selections, click this button to apply the namespaces to all selected scripts.

Key Features

  • Automatic Generation: Creates namespaces from folder paths.
  • Batch Processing: Updates hundreds of scripts at once.
  • Folder Overrides: Set custom namespaces for specific folders.
  • Selective Updating: Choose which scripts to update.
  • Editor Script Awareness: Identifies and correctly handles editor scripts.
  • Non-Destructive: Previews all changes before you apply them.
  • Persistent Settings: Your folder overrides are saved between Unity sessions.

Compatibility

This package requires Unity 2020.3 or newer.
